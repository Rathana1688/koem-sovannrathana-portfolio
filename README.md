# KOEM SOVANNRATHANA — Portfolio

A responsive single-page portfolio built with React, Vite, Tailwind CSS v4, and Lucide icons.

## Requirements
- Node.js 20.19+ or 22.12+
- npm

## Run locally
1. Extract this folder.
2. Open the folder in VS Code.
3. Open Terminal in VS Code.
4. Install packages:
   ```bash
   npm install
   ```
5. Start the development server:
   ```bash
   npm run dev
   ```
6. Open the local URL shown in the terminal (usually http://localhost:5173).

## Production build
```bash
npm run build
npm run preview
```
